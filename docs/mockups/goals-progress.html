Goals on the Progress screen

Mock-up, 13 Aug 2026. Every number below is real data pulled from the live database — Dustin, Lauren and Robert's actual weigh-ins — because a mock-up with invented numbers hides exactly the cases that matter. These three are genuinely different situations, and the screen has to handle all three without lying to anyone.

The honest constraint, up front: there are 95 weigh-ins in the whole database across 23 clients — about four each. Robert has four. Lauren has five. A projection drawn from four points is a guess wearing a suit, so the design says so out loud rather than drawing a confident dashed line through thin air: under six weigh-ins the projection is replaced by "log a few more and I can tell you where this lands." The feature that makes goals work is more frequent weigh-ins. Worth deciding whether the goal screen should ask for one when it's stale.

What I'd want your eye on: whether the "behind pace" wording lands right — that's Lauren's and Robert's cards. Whether the projection dashed line is useful or alarming. Whether a goal you set should really be refusable, or just discussable. And whether the progress meter helps or whether the chart alone says it.
