Progress screen with goals — interactive

v2, 13 Aug 2026. Click things: switch client, drag across the chart, change the range, open the coach, set a goal, log a weigh-in. Real weigh-ins from the live database throughout.

Nothing existing moves. Goals are three new cards inserted above what's already there. Metric tiles, consistency calendar, achievements, photos, Then vs Now and personal bests are untouched — they're shown below the new cards, marked UNCHANGED, so you can see exactly where the seam is. No existing component gets edited, so no existing chart can break.
